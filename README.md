# 🚀 AI Interview Preparation Platform

An AI-powered interview preparation platform that helps users practice technical interviews, analyze resumes, and receive intelligent feedback using Google's Gemini AI.

---

## 📌 Project Overview

The AI Interview Preparation Platform is a full-stack web application that allows users to:

- 👤 Register and Login securely
- 🤖 Practice AI-generated interview questions
- 📄 Upload resumes (PDF/DOCX)
- 🎯 Attend Resume-Based AI Interviews
- 📊 Track interview performance
- 📚 View interview history
- ⭐ Receive AI-generated feedback and scores

The platform is built using the MERN Stack and integrated with Google Gemini AI for intelligent interview evaluation.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Pardhu-2005558/AI-Interview-Preparation-Platform.git
```

Move into the project

```bash
cd AI-Interview-Preparation-Platform
```

---

## Backend

```bash
cd server
npm install
npm start
```

---

## Frontend

```bash
cd client
npm install
npm run dev
```

---

# 🔑 Environment Variables

Create a `.env` file inside the server folder.

```env
MONGO_URI=Your MongoDB URI
JWT_SECRET=Your JWT Secret
GEMINI_API_KEY=Your Gemini API Key
PORT=5000
```
